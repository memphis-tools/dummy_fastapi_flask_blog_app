A project that actually runs.

RUNNING

Not a mockup. Not a tutorial. A Flask + FastAPI micro-social platform on Docker Swarm — designed, broken, secured, and kept alive in production for years.

Nginx fronts the stack, Certbot delivers free HTTPS, hCaptcha keeps bots out. Behind the curtain: PostgreSQL, Celery chewing through a RabbitMQ broker with a Redis backend, HashiCorp Vault guarding the secrets, and SendGrid + Mailtrap carrying every email.

GitLab runs the CI/CD heartbeat — tests, build, publish on every master push. Terraform raises the DigitalOcean droplet, Cloudflare takes the hits, NameCheap owns the name, ConsentManager handles consent. Betterstack watches the logs, Codacy judges the code, Snyk + Aikido hunt app-level flaws and Lynis audits the system.

Even the tests have a story: TabNine and Cursor helped build the suite — and since 2026, Mistral-vibe finishes the test coverage. Fully AI-assisted, human-verified.

Learn it. Repeat it.

17 virtual machines. One command: vagrant up. A disposable Linux laboratory for LPIC certification — and for breaking things on purpose.

DNS primary and secondary, Kerberos KDC, OpenLDAP, vsFTP, Squid with and without SSL bumping, Dovecot mail, OpenVPN, a bastion with its own SSH certificate authority, Bacula backups, NAS storage and a log analyzer — every machine plays a real infrastructure role, provisioned by Ansible.

From RHEL 4-era habits to today's systemd and firewall-cmd world: LUKS, self-signed CAs, TSIG keys, nmap, SELinux thinking. A lab built to be destroyed and rebuilt — that's the point.

SMALL PIPELINE / FAST FEEDBACK

Build small. Ship often.

A Django blog, backend-first, pushed to Render by CircleCI — the same DevOps ideas, deliberately fewer moving parts.

In production: native Python on Render. No Docker, no Gunicorn, no Nginx. Locally: the full container experience with Gunicorn and Nginx via docker-compose. CircleCI runs the workflow, Coveralls tracks coverage, Poetry keeps dependencies honest.

And the honest lesson of free tiers: instances spin down when idle, so the first visitor after a nap waits 50+ seconds. Cold starts, live, as a feature.
